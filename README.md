# Laptop Dashboard Bot

A tiny Flask web dashboard that runs on a laptop (`http://localhost:5000`) and exposes big, touch-friendly buttons for everyday actions — designed for a user who prefers large text and simple controls.

## Features

- 📸 One-tap screenshot capture (viewed right in the page)
- 🌐 Open any website by typing its address
- 🎨 "Designer" graphics section

## Tech stack

- Python + Flask (single file, no build step)

## Run

```sh
pip install flask
python dashboard.py
# open http://localhost:5000
```
